# 学徒行用户端（uni-app / Vue 3）

这是学徒行用户端，适配 H5、App、微信小程序。主要功能包括：登录注册、邀请积分、旅行路线、人工深度定制、学习服务商城、余额购买、在线客服、平台公告、入驻学校、个人中心。

## 运行前准备

先确认后端已启动：

```text
http://127.0.0.1:8000/health
```

返回 `status: ok` 说明后端正常。

## 用 HBuilderX 运行

1. 打开 HBuilderX。
2. 选择「文件 -> 导入 -> 从本地目录导入」。
3. 选择 `outputs/xuetuxing`。
4. H5 测试：选择「运行 -> 运行到浏览器」。
5. 微信小程序测试：在 `manifest.json` 填写小程序 AppID，再运行到微信开发者工具。
6. App 测试：使用 HBuilderX 云打包或本地打包。

这是 uni-app Vue 3 项目，不是普通 Vue 项目，不建议直接用 `npm run dev` 启动。

## API 地址规则

统一在 [utils/api.js](./utils/api.js) 中管理。

默认规则：

| 场景 | API |
|---|---|
| H5 localhost | `http://127.0.0.1:8000/api/v1` |
| H5 局域网访问 | `http://当前局域网IP:8000/api/v1` |
| H5 部署到服务器 | 当前域名 `/api/v1` |
| App 打包 | `http://113.44.149.128/api/v1` |
| 微信小程序 | `http://113.44.149.128/api/v1`，正式发布要换 HTTPS 域名 |

临时切换环境：

```js
uni.setStorageSync('apiEnvironment', 'local')       // 本机
uni.setStorageSync('apiEnvironment', 'lan')         // 局域网
uni.setStorageSync('apiEnvironment', 'production')  // 公网
uni.setStorageSync('apiEnvironment', 'auto')        // 自动判断
uni.removeStorageSync('apiBaseUrl')                 // 清理旧手动地址
```

## 旅行合同签名

用户端入口：`/pages/mine/travel`。

流程：

1. 页面调用 `GET /api/v1/travel/orders` 获取当前用户旅行订单。
2. 打开合同弹窗时调用 `GET /api/v1/travel/contract-template` 获取平台维护的合同标题、正文和可选出行日期。
3. 用户查看合同历史、合同正文，选择出行日期。
4. 填写签署人、联系电话、证件号。
5. 在签名画板手写签名并提交。
6. 后端保存出行日期、签署信息和签名图，并设置 `travel_orders.contract_status = pending`。
7. 管理后台订单审核中心审核合同，通过后变为 `approved`；驳回后用户可看到原因并重新签署。

## 用户常用流程

### 注册登录

1. 我的 -> 点击头像区域。
2. 未登录时进入登录/注册页。
3. 注册后需要管理端审核。
4. 审核通过后用户才能登录。

### 邀请积分

1. 首页或我的积分进入邀请页。
2. 生成邀请海报或复制邀请链接。
3. 新用户通过邀请码注册。
4. 邀请人增加积分。
5. 满足积分后可兑换泰山游。

### 人工深度定制旅行

1. 旅行 -> 路线详情 -> 人工深度定制。
2. 填写目的地、时间、天数、预算、人数和特殊需求。
3. 提交后进入待审核状态。
4. 管理后台审核并填写方案。
5. 用户端方案页展示审核通过后的完整方案。

### 学习服务余额购买

1. 进入学习服务商城。
2. 选择学习产品。
3. 打开服务详情。
4. 使用账户余额购买。
5. 支付成功后进入学习中心查看权益。

订单提交保护：

- 收银台支付按钮在加载中和支付中会禁用。
- 同一次进入收银台会生成并复用一个 `idempotency_key`，弱网或重复点击不会创建多张同款订单。
- 后端余额支付会再次做订单状态和余额锁定，避免同一订单重复扣款。
- 收银台倒计时默认 30 分钟，与后端未支付订单自动取消时间一致。

订单异常自查：

1. 先到学习中心确认订单是否出现。
2. 如果订单已支付但权益没显示，返回学习中心下拉刷新或重新进入页面。
3. 如果提示余额不足，先到「我的」确认余额是否够本次应付金额。
4. 如果支付失败但生成了待支付订单，可重新进入收银台再支付；后台会按订单状态判断，不会重复扣同一订单。
5. 需要后台排查时，把学习中心显示的订单号 `order_no` 发给管理员。

### 在线客服

1. 用户端客服默认连接平台客服。
2. 学习订单详情可联系对应商户客服。
3. 平台客服可参与用户与商户的订单会话。
4. 支持文字、图片、历史记录和本地图片缓存。

## 微信小程序发布注意事项

正式发布前必须处理：

- 后端必须使用 HTTPS 域名，不能只用 IP + HTTP。
- 在微信公众平台配置：
  - request 合法域名
  - uploadFile 合法域名
  - downloadFile 合法域名
  - socket 合法域名
- 图片资源域名也要是 HTTPS。
- 如果使用 OBS，建议通过后端代理地址展示图片，避免桶权限问题。
- `manifest.json` 填写正式 AppID。

## App 打包注意事项

- Android 如需访问 HTTP，需要在原生配置中允许 cleartext。
- 修改 Android 原生权限后，需要重新打包，热更新不生效。
- 打包后如果登录/注册没有请求记录，先在登录页点击「检测公网连接」确认实际 API 地址。

## 常见问题

### 1. 页面提示接口连接失败

检查：

```text
http://113.44.149.128/health
http://113.44.149.128/api/v1/public/config
```

如果服务器没有请求记录，说明前端 API 地址没有指向公网。

### 2. 小程序无法请求 HTTP

正式微信小程序不允许 HTTP，必须配置 HTTPS 域名。

### 3. 图片加载慢

项目已做本地缓存和缩略图策略。仍然慢时检查：

- OBS 是否同区域
- 图片是否太大
- 后端缩略图接口是否正常
- 是否每次都绕过缓存

### 4. 装修内容没有同步

管理端要点击「发布」，用户端读取的是已发布内容，不是草稿。
